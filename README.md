## วิธีการใช้หลักสูตร

1. เริ่มจาก Part 01 และทำตามลำดับ
2. แต่ละ Part มีตัวอย่างโค้ดที่ใช้งานได้จริง
3. ทำแบบฝึกหัดท้ายแต่ละ Part ก่อนไปต่อ
4. สร้าง project จริงตาม Workshop ที่กำหนด

## ความต้องการพื้นฐาน

- Computer ที่รัน macOS, Windows, หรือ Linux
- RAM อย่างน้อย 8GB (แนะนำ 16GB)
- พื้นที่ว่างอย่างน้อย 20GB
- ไม่จำเป็นต้องมีความรู้การเขียนโปรแกรมมาก่อน
